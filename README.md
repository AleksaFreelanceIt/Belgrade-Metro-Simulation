# Belgrade Metro Simulation

An independent software engineering project focused on modeling, simulating, and managing a metro transportation network in Belgrade.

## Overview

Belgrade Metro Simulation aims to explore how a metro transportation system can be modeled and operated through software.

The project focuses on creating a simulation of a metro network, representing its infrastructure and operational behavior. It is designed to provide a foundation for experimenting with railway scheduling, train movement, network management, and optimization algorithms.

Originally conceived as an idea for a university project, it has since evolved into an independent, long-term software development project.

## Objectives

- **Network Modeling** – Represent metro stations, tracks, connections, and routes.
- **Train Simulation** – Model train movement and interactions within the network.
- **Traffic Management** – Explore strategies for coordinating train operations and managing railway traffic.
- **Scheduling Optimization** – Investigate algorithms for improving train schedules and minimizing delays.
- **Visualization** – Provide a graphical representation of the metro network and its operational state.

## Technologies

- **C++** – Core simulation logic and system architecture.
- **Qt** – Graphical user interface and visualization.

## Project Goals

The long-term goal is to develop a modular and extensible metro simulation platform that can be used to experiment with different railway management strategies and optimization techniques.

The project will evolve incrementally, with an emphasis on software architecture, algorithmic efficiency, and realistic modeling of transportation systems.
